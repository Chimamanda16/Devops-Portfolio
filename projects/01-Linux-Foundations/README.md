# 01 Linux Foundations - Enterprise Linux Server Operations & Access Control Platform

## Problem Description
I am part of the infrastructure team at a growing technology company. The company has Linux servers supporting internal applications, engineering teams, operational reports, and sensitive configuration files.

The existing setup has problems:

Engineers have inconsistent access to files and directories.
Some employees have more permissions than their roles require.
Important operational files are scattered across the filesystem.
Administrators cannot easily determine who owns a file or why a user cannot access it.
There is no standardized procedure for onboarding and offboarding staff.
When something goes wrong, the team relies on manual investigation instead of a documented process.

## Task assignment
My assignment is to build a repeatable Linux server administration environment that establishes a sensible filesystem structure, manages identities and permissions, verifies access boundaries, and provides evidence that the environment is working correctly.

## Structure
+ /docs - contains documentation files includeing operations runbook, incident report, architecture and access-policy
+ /evidence - contains evidence of errors, failures and inconsistencies in the organization, their causes and fixes
+ /tests - contains key things verified at the end of the project

## Concepts Learned
+ Shell, Linux, kernel
+ Virtual machines, installations and usage
+ Basic linux commands, users, groups, access and identities
