# DevOps Projects Portfolio

## Description
This repository contains hands-on projects completed as part of my DevOps learning journey. Each project is built around realistic operational scenarios and focuses on practical, real-world skills and challenges rather than just theory or quizzes.

The actual technical work (users, groups, permissions, services, etc.) is performed on a dedicated Linux virtual machine. This repository is used to document the work, store architecture decisions, access policies, runbooks, incident reports, and verification evidence.

## Structure
Each project lives in its own folder under `projects/` and typically contains:

- `README.md` — Problem statement and overview
- `docs/` — Architecture, access policies, runbooks, and incident reports
- `evidence/` — Screenshots and verification results
- `tests/` — Manual or automated verification checks, if applicable
